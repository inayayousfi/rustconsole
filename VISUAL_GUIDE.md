# Rust Console visual guide

The Rust Console mark is a curved X drawn from four rising and falling arms around a small central opening. Keep the mark free of circles, enclosing rings, and extra cuts.

## Color

The mark uses a diagonal gradient from deep red at the lower left to bright red at the upper right.

| Use | Color |
| --- | --- |
| Gradient start | `#b00020` |
| Gradient end | `#ff1744` |
| Main background | `#111318` |
| Raised background | `#171a21` |
| Light foreground | `#f7f7f8` |

## Spacing

Leave clear space around the mark equal to one eighth of its width. Do not stretch, rotate, outline, or rearrange the mark.

`logo.svg` is the source artwork. Generate raster sizes from that file instead of editing separate copies.
